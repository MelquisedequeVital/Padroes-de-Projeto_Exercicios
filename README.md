# Padrões de Projeto

Exercícios da disciplina de Padrões de Projeto, organizados por padrão. Cada pasta tem um README que explica o padrão e mostra o UML de exemplo.

| Padrão | Categoria | Exercícios |
|---|---|---|
| [Chain of Responsibility](Chain_of_Responsibility) | Comportamental | `dispensadora_cedulas_atm`, `processamento_pedidos_ecommerce`, `processo_seletivo_simplificado_pps`, `suporte_tecnico` |
| [State](State) | Comportamental | `monitoramento_envio_pedido`, `quiosque_inscricao_incompleto`, `semaforo`, `turing_machine` |
| [Strategy](Strategy) | Comportamental | `processamento_transacoes_pagamento` (+ Chain) |
| [Template Method](Template_Method) | Comportamental | `social_network_template` |
| [Decorator](Decorator) | Estrutural | `frete_decorator`, `text_decorator` |
| [Factory Method](Factory_Method) | Criacional | `processamento_transacao_factory` (+ Template Method) |
| [Simple Factory](Simple_Factory) | Criacional | `simple_factory_notification`, `refactoring_example_locadora` |

Quando um exercício usa mais de um padrão, ele fica na pasta do padrão principal, e o README do outro padrão aponta para ele.
